# 偏心我 · pianxin.me

两个人的小空间：`/zhengwang` 和 `/xiaoha`。

- **一起模式**：自习 / 阅读 / 运动 / 吃饭 / 观影 / 睡觉，共用一个同步计时；专注时聊天自动收起、静音、只能发表情，休息时展开
- **状态卡**：心情 + 需求（想聊天 / 想安静 / 求安慰 / 只想吐槽），今日目标、任务、做题计数；对方勾掉任务、做完一道题时边上弹出不打扰的小提示
- **戳一下**、抱抱、我在听
- **草稿栏**：文字 + 手写，双方实时可见
- **记录**：日历形式的生活点滴，图片 + 文字，对自己说（只存本机）/ 对 TA 说
- **健身专区**、**吃饭专区**（吃了啥、可展开的共享菜谱、吃货心愿单）
- **我们的小日历**：纪念日、见面倒计时、共同计划、约会点子罐
- 没有连续打卡、已读回执、陪伴时长排行——打开它只是因为想念

## 怎么工作的

纯静态站点（GitHub Pages），没有自己的服务器：

- 两个人输入同一个暗号 → PBKDF2（30 万次）派生出 AES-256-GCM 密钥和房间号
- 所有内容先在浏览器里加密，再经两条公共 MQTT over WSS 线路（EMQX、HiveMQ）互相传递；保留消息充当加密信箱，不同时在线也能收到
- 每个人的数据完整保存在自己浏览器的 IndexedDB 里（local-first），可在设置页导出备份
